## 工具作用和用法

badblocks 

名字：用于检查磁盘装置中损坏的区块。执行指令时须指定所要检查的磁盘装置，及此装置的磁盘区块数。

概要：**badblocks** [ **-svwnf** ] [ **-b** *block-size* ] [ **-c** *blocks_at_once* ] [ **-e** *max_bad_blocks* ] [ **-d** *read_delay_factor* ] [ **-i** *input_file* ] [ **-o** *output_file* ] [ **-p** *num_passes* ] [ **-t** *test_pattern* ] *device* [ *last-block* ] [ *first-block* ]

描述：

举例：badblocks -s -v /dev/sdnx

`e2image`

名称：用于备份或恢复 ext2、ext3 或 ext4 文件系统的工具。

概要：**e2image** [ **-ciprTv** ] [ **-b** *block-size* ] [ **-f** *fragment-size* ] [ **-S** *sparse-block-size* ] [ **-O** *creator-os* ] [ **-h** *hash-size* ] [ **-l** *lazy-itable-size* ] [ **-L** *lazy-blocks* ] [ **-n** *hash-function* ] [ **-N** *number-of-blocks* ] [ **-z** *compression-method* ] [ **-E** *options* ] [ **-C** *compression-level* ] [ **-v** ] *source* *destination*

示例：e2image -r /dev/sda1 /backup/sda1_backup.img

概要：**e4crypt** [ **-c** ] [ **-v** ] [ **-S** ] [ **-U** ] [ **-Q** ] [ **-T** ] [ **-C** ] [ **-P** ] [ **-E** ] [ **-D** ] [ **-M** ] [ **-A** *android-data-partition* ] [ **-R** *key_location* ] [ **-S** *salt_location* ] [ **-P** *password_location* ] [ **-E** *empty_password_location* ] [ **-T** *token_location* ] [ **-V** *volume_id* ] *directory*...



fsck.ext3

名称：用于检查和修复 ext3 文件系统的工具。

概要：fsck.ext3 [选项] 设备

选项：

  -b superblock      指定备用超级块。
  -B blocksize       设置文件系统块大小（字节）。
  -C fd              显示进度条给文件描述符。
  -c [fd]            检查文件系统是否有损坏，但不修复。
  -d                 调试模式。
  -f                 强制检查，即使文件系统似乎干净。
  -j                 如果文件系统未挂载，将强制重新装载为ext3。
  -n                 不要执行任何动作，仅显示要执行的操作。
  -p                 预览要执行的操作，但不要执行任何操作。
  -r                 交互式修复模式。
  -v                 详细模式。
  -y                 对所有问题都自动回答“是”。
  -V                 打印出版本信息。

设备：要检查的文件系统所在的设备。

常用示例：
fsck.ext3 /dev/sda1



mkfs.ext4

名称：用于创建 ext4 文件系统的工具。

概要：mkfs.ext4 [选项] 设备 [大小]

选项：

  -b  block-size       指定文件系统的块大小。
  -c  max-mount-counts 指定在执行完全系统检查之前应运行的最大安装计数。默认值为-1表示禁用此功能。
  -C  checkpoint-interval
                       使用位图检查点功能，并设置检查点之间的最大事务数。默认值为-1表示禁用此功能。
  -E  extended-options  使用指定的扩展选项。有关可用选项的信息，请参见 mke2fs(8) 的“扩展选项”部分。
  -i  bytes-per-inode  指定每个文件系统块的字节数。
  -I  inode-size       指定要创建的新文件系统的inode大小（以字节为单位）。
  -j                   创建ext3文件系统（与mkfs.ext3相同）。
  -J  journal-options  使用指定的日志选项。有关可用选项的信息，请参见 mke2fs(8) 的“日志选项”部分。
  -l  label            设置文件系统标签。
  -m  reserved-blocks-percentage
                       保留用于超级用户（root）的文件系统块的百分比。
  -M  last-mounted-directory
                       设置上次挂载文件系统的目录。
  -n  num-inodes       创建新文件系统时要保留的inode数量。
  -N  number-of-inodes 创建新文件系统时要保留的inode数量。
  -O  feature[,...]    使用指定的文件系统功能。有关可用选项的信息，请参见 mke2fs(8) 的“文件系统功能”部分。
  -q                   以安静模式执行，不打印出任何提示或警告。
  -r  fs-revision      指定文件系统版本。默认为1（适用于 ext2 和 ext3）。
  -T  filesystem-type  指定文件系统类型。
  -v  版本信息
  -V  Print version and exit.

设备：要创建文件系统的设备。

大小：文件系统大小。如果不提供，则将使用整个设备。

举例：

  1. 创建一个大小为 1GB 的 ext4 文件系统在 /dev/sda1 设备上：

     mkfs.ext4 /dev/sda1 1G

  2. 创建一个块大小为 4096 字节，标签为 "data" 的 ext4 文件系统在 /dev/sdb1 设备上：

     mkfs.ext4 -b 4096 -l data /dev/sdb1

blkid

名称：用于显示或扫描块设备的文件系统类型和属性。

概要：blkid [选项] [块设备]

选项：

  -c device          设置 blkid 使用的缓存文件。
  -g                 使用 cache 文件。
  -p                 使用原始设备模式。
  -s attribute       显示指定的属性。
  -t token           使用指定的标记。
  -u uuid            按 UUID 显示设备信息。
  -g 或 -p 选项使用的默认文件是 /etc/blkid.tab。

块设备：要显示信息的块设备。

举例：

  1. 显示所有块设备的文件系统类型和属性：

     blkid

  2. 显示 /dev/sda1 设备的 UUID：

     blkid -u uuid /dev/sda1

e2label

名称：用于设置或显示 ext2/ext3/ext4 文件系统的卷标。

概要：e2label [选项] 设备 [新卷标]

选项：

  -c     检查设备并尝试恢复破坏的文件系统。
  -L     显示当前的卷标。
  -n     不要执行实际写入操作。
  -v     显示详细信息。
  -E     将文件系统转换为 32 位计数。
  -Eoffset=xxx
         设置文件系统的起始位置。
  -Ehash_seed=xxx
         设置哈希种子。
  -Ehash_alg=xxx
         设置哈希算法。
  -Eencoding=xxx
         设置文件名编码。
  -Einline_data
         启用内联数据选项。
  -Euser_xattr
         启用用户扩展属性。
  -Eacl  启用 ACL。
  -Edirectory_index
         启用目录索引。

设备：要设置或显示卷标的设备。

新卷标：要设置的新卷标。

举例：

  1. 显示 /dev/sda1 设备的当前卷标：

     e2label /dev/sda1

  2. 将 /dev/sdb1 设备的卷标设置为 "data"：

     e2label /dev/sdb1 data

e4defrag

名称：用于对 ext4 文件系统执行在线碎片整理。

概要：e4defrag [选项] 设备

选项：

  -c, --check     只检查文件系统的碎片情况，不执行碎片整理。
  -v, --verbose   显示详细的操作信息。
  -y, --yes       无需确认，直接执行碎片整理。
  -h, --help      显示帮助信息。
  -V, --version   显示版本信息。

设备：要对其执行碎片整理的 ext4 文件系统设备。

举例：

  1. 对 /dev/sda1 设备上的 ext4 文件系统执行碎片整理，并显示详细信息：

     e4defrag -v /dev/sda1

  2. 检查 /dev/sdb1 设备上的 ext4 文件系统的碎片情况：

     e4defrag -c /dev/sdb1

mklost+found

名称：用于创建一个用于恢复丢失文件的 lost+found 目录。

概要：mklost+found [选项] 文件系统

选项：

  -c, --clear     清空现有的 lost+found 目录。
  -d, --debug     显示调试信息。
  -h, --help      显示帮助信息。
  -V, --version   显示版本信息。

文件系统：要为其创建 lost+found 目录的文件系统。

说明：

mklost+found 命令用于创建一个用于恢复丢失文件的 lost+found 目录。该目录通常位于文件系统的根目录下，并由文件系统的管理程序使用。

举例：

  1. 在 /dev/sda1 文件系统上创建 lost+found 目录：

     mklost+found /dev/sda1

  2. 清空 /dev/sdb1 文件系统上的 lost+found 目录：

     mklost+found -c /dev/sdb1

debugfs

名称：用于检查和调试 ext 文件系统。

概要：debugfs [选项] [设备|文件系统]

选项：

  -b 文件        使用文件作为调试文件系统。
  -c            显示文件系统的配置信息。
  -f 文件        从文件中读取命令并执行。
  -R 命令        执行指定的命令并退出。
  -v            显示详细的信息。
  -d            启用调试输出。
  -D            显示调试输出的详细信息。
  -q            安静模式，不输出提示信息。
  -l 文件        将输出重定向到文件。
  -s            交互模式。
  -r            运行时修改检测。
  -w            启用读写模式。
  -y            启用自动应答模式。

设备|文件系统：要检查和调试的设备或文件系统。

说明：

debugfs 是一个用于检查和调试 ext 文件系统的命令行工具。它提供了一组命令，允许用户对文件系统执行各种操作，如查看和修改 inode 信息、修复文件系统错误、以及执行其他调试操作。

常用命令：

  - cd 路径      切换到指定路径。
  - cat 文件     显示文件内容。
  - dump [选项]  显示文件的数据块。
  - ls [-l] 路径 显示路径下的文件列表。
  - stat 文件    显示文件或目录的统计信息。
  - quit         退出 debugfs。

举例：

  1. 检查 /dev/sda1 文件系统：

     debugfs /dev/sda1

  2. 在交互模式下查看 /dev/sda1 文件系统中的文件列表：

     debugfs -s /dev/sda1

  3. 从命令文件中执行一系列操作：

     debugfs -f cmds.txt /dev/sda1

e2mmpstatus

名称：显示 ext4 文件系统的多重元数据更新（MMP）状态。

概要：e2mmpstatus [选项] [设备|文件系统]

选项：

  -h, --help            显示帮助信息并退出。
  -V, --version         显示版本信息并退出。
  -v, --verbose         显示详细的信息。

设备|文件系统：要显示 MMP 状态的设备或文件系统。

说明：

e2mmpstatus 是一个用于显示 ext4 文件系统的多重元数据更新（MMP）状态的命令行工具。MMP 是一种机制，用于检测并防止多个文件系统实例同时进行元数据更新，以避免文件系统损坏。

常用命令：

  - e2mmpstatus /dev/sda1    显示 /dev/sda1 文件系统的 MMP 状态。
  - e2mmpstatus -v /dev/sdb   显示 /dev/sdb 文件系统的详细 MMP 状态。

示例：

  1. 显示 /dev/sda1 文件系统的 MMP 状态：

     e2mmpstatus /dev/sda1

  2. 显示 /dev/sdb 文件系统的详细 MMP 状态：

     e2mmpstatus -v /dev/sdb

filefrag

名称：显示文件在文件系统中的碎片化信息。

概要：filefrag [选项] [文件...]

选项：

  -b, --block-size=<size>    设置文件系统块的大小。
  -v, --verbose               显示更详细的输出信息。
  -z, --zeros                 显示已经被初始化为零的块的信息。
  -s, --sync                  同步文件系统，然后再显示信息。
  -h, --help                  显示帮助信息并退出。
  -V, --version               显示版本信息并退出。

文件：要显示碎片化信息的文件。

filefrag 是一个用于显示文件在文件系统中的碎片化信息的命令行工具。它会输出文件的逻辑块号和它们在磁盘上的物理块号，以及任何碎片化的信息。

常用命令：

  - filefrag /path/to/file    显示指定文件的碎片化信息。
  - filefrag -v /path/to/file    显示指定文件的详细碎片化信息。
  - filefrag -b 4096 /path/to/file    设置文件系统块大小为 4096 字节，然后显示指定文件的碎片化信息。

  1. 显示指定文件的碎片化信息：

     filefrag /path/to/file

     filefrag -v /path/to/file

  3. 设置文件系统块大小为 4096 字节，然后显示指定文件的碎片化信息：

     filefrag -b 4096 /path/to/file

logsave

名称：保存命令的输出到日志文件中。

概要：logsave [选项] [日志文件] [命令]

选项：

  -a, --append          将输出追加到现有日志文件中。
  -c, --create          创建一个新的日志文件。
  -t, --timestamp       在每行前面加上时间戳。
  -h, --help            显示帮助信息并退出。
  -V, --version         显示版本信息并退出。

日志文件：保存命令输出的日志文件。

命令：要执行并保存输出的命令。

说明：

logsave 命令用于将命令的输出保存到日志文件中。可以指定日志文件的名称，并选择是追加到已存在的日志文件还是创建一个新的日志文件。可以选择在每行的前面添加时间戳。如果不指定日志文件，则默认将输出保存到 /var/log/messages 文件中。

常用命令：

  - logsave mylog.txt ls -l    将 ls -l 命令的输出保存到 mylog.txt 文件中。
  - logsave -a mylog.txt df -h    将 df -h 命令的输出追加到 mylog.txt 文件中。
  - logsave -c mylog.txt ps aux    创建一个新的 mylog.txt 文件，并将 ps aux 命令的输出保存到其中。
  - logsave -t mylog.txt top    将 top 命令的输出保存到 mylog.txt 文件中，并在每行前添加时间戳。

示例：

  1. 将 ls -l 命令的输出保存到 mylog.txt 文件中：

     logsave mylog.txt ls -l

  2. 将 df -h 命令的输出追加到 mylog.txt 文件中：

     logsave -a mylog.txt df -h

  3. 创建一个新的 mylog.txt 文件，并将 ps aux 命令的输出保存到其中：

     logsave -c mylog.txt ps aux

  4. 将 top 命令的输出保存到 mylog.txt 文件中，并在每行前添加时间戳：

     logsave -t mylog.txt top

resize2fs

名称：调整 ext2/ext3/ext4 文件系统大小。

概要：resize2fs [选项] *device* [大小]

选项：

  -p, --print               打印文件系统的信息，但不进行任何操作。
  -d, --debug               打印调试信息。
  -f, --force               强制执行，即使可能会导致文件系统损坏。
  -F, --fragments           将大小指定为块数量，而不是字节数。
  -M, --min                将文件系统大小设置为最小值。
  -P, --profile             输出性能数据到标准输出。
  -S, --resize-fs           仅调整文件系统大小，而不更改存储设备的大小。
  -s, --size                设置文件系统的大小。
  -M, --metadata-csum       启用元数据校验和。
  -M, --resize_inode        启用 inode 表的调整。
  -T, --test                测试模式，不实际执行操作。
  -v, --verbose             详细输出。
  -V, --version             显示版本信息并退出。
  -z, --lazy_itable_init    延迟初始化 inode 表。

说明：

resize2fs 命令用于调整 ext2/ext3/ext4 文件系统的大小。必须指定设备作为参数，resize2fs 将根据提供的大小参数调整文件系统大小。

常用命令：

  - resize2fs /dev/sda1    调整 /dev/sda1 分区的文件系统大小。
  - resize2fs -s /dev/sda1 10G    将 /dev/sda1 分区的文件系统大小调整为 10GB。
  - resize2fs -M /dev/sda1    将 /dev/sda1 分区的文件系统大小设置为最小值。

示例：

  1. 调整 /dev/sda1 分区的文件系统大小：

     resize2fs /dev/sda1

  2. 将 /dev/sda1 分区的文件系统大小调整为 10GB：

     resize2fs -s /dev/sda1 10G

  3. 将 /dev/sda1 分区的文件系统大小设置为最小值：

     resize2fs -M /dev/sda1

e2scrub [选项] 设备

选项：
  -a, --all     对文件系统中的所有块进行检查。

e2scrub 命令用于在线检查 ext4 文件系统的块一致性，可以检测并修复文件系统中损坏的块。需要指定设备作为参数。

e2scrub /dev/sda1       # 对 /dev/sda1 分区执行块一致性检查和修复。
e2scrub -a /dev/sdb1    # 对文件系统中的所有块执行检查。
e2scrub -s /dev/sda1    # 打印 /dev/sda1 分区文件系统中块的检查状态。

findfs [选项] 文件系统标签或UUID

选项：
  -V, --version  显示版本信息并退出。

findfs LABEL=myfilesystem     # 根据文件系统标签查找对应的设备路径。

mke2fs [选项] [-t ext2|ext3|ext4] 设备 [blocks]

选项：
  -v, --verbose               显示详细的输出信息。
  -V, --version               显示版本信息并退出。
  -t, --type=TYPE             指定文件系统类型为 ext2、ext3 或 ext4。
  -b, --block-size=SIZE       设置块大小（单位：字节）。
  -i, --bytes-per-inode=SIZE  设置每个inode占用的字节数。
  -I, --inode-size=SIZE       设置inode的大小（单位：字节）。
  -N, --resize-fs=COUNT       为文件系统设置inode计数（仅用于resize2fs）。
  -m, --reserved-percent=PERCENT
                              为超级用户保留百分比的文件系统空间。
  -O, --feature=^feat1,...    禁用指定的文件系统特性。
  -g, --group=NUMBER          设置每个组中的块数。
  -G, --large-file            使用64位文件大小。
  -j, --journal-location=位置 设置日志文件的位置。
  -J, --journal-options=选项  设置日志选项。
  -E, --extended-options[=list]
                              设置扩展选项（用逗号分隔的选项列表）。
  -d, --hash-algorithm=名称   设置目录索引的哈希算法（hmac(md5)，hmac(sha1)，hmac(sha256)，hmac(sha512)）。
  -E discard                  启用TRIM/discard支持（仅用于ext4和f2fs）。
  -E nodelalloc               禁用延迟分配（仅用于ext4）。
  -E lazy_itable_init         延迟初始化inode表。
  -E lazy_journal_init        延迟初始化日志。
  -E resize=SIZE[K|M|G]       创建文件系统时调整其大小。
  -E stride=STRIDE-size       设置文件系统的stride（以块为单位）。
  -E stripe-width=STRIDE-size 设置文件系统的条带宽度（以块为单位）。
  -O ^metadata_csum           禁用元数据校验和特性。
  -O ^64bit                   禁用64位文件系统支持。
  -O ^has_journal             禁用日志功能。
  -O ^dir_index               禁用目录索引。
  -O ^ext_attr                禁用扩展属性。
  -O ^resize_inode            禁用inode调整大小功能。
  -O ^flex_bg                 禁用灵活块组。
  -O ^huge_file               禁用大文件支持。
  -O ^uninit_bg               禁用未初始化块组。
  -O ^dir_nlink               禁用链接计数目录。
  -q, --quiet                 安静模式。不输出警告和进度信息。

示例：
  mke2fs /dev/sdb1           # 创建一个默认参数的ext2文件系统。
  mke2fs -t ext4 /dev/sdc1    # 创建一个ext4文件系统。
  mke2fs -j /dev/sdd1        # 创建一个ext3文件系统，并启用日志。

e2fsck - 检查一个 ext2/ext3/ext4 文件系统

概要
       e2fsck [ -pacnyrdfkvtDFV] [ -b superblock] [ -B blocksize] [ -l|-L bad_blocks_file]
       [ -C fd] [ -j external-journal] [ -E extended-options] [ -z undo_file] [ -P progress_fd]
       [ -R region_size] [ -m bad_blocks_behavior] [ -S last mounted filesystem] [ -T last_checked]
       device

描述
       e2fsck 用于检查 Linux second extended 文件系统（即 ext2/ext3/ext4 文件系统）的完整性，并在可能的情况下尝试修复损坏。如果没有指定设备，则将从 /etc/fstab 文件中查找包含根文件系统的设备。

       通常情况下，这个程序使用 mount 命令检查启动时需要检查的文件系统，所以它通常不需要手工执行。

选项
       -a     自动修复文件系统，不询问用户。仅适用于非交互式模式。

       -b superblock
              用指定的备用超级块替代默认的超级块。通常，系统会使用文件系统的备份超级块。
    
       -B blocksize
              指定每个块的大小（以字节为单位）。有效的块大小值为 1024、2048 和 4096。
    
       -c     检查文件系统，而不执行任何动作。
    
       -C fd  将 e2fsck 的进度信息写入指定的文件描述符。
    
       -d     显示调试输出（仅供调试使用）。
    
       -D     启用调试输出级别。debugfs 将打印大量信息。
    
       -E extended-options
              扩展 e2fsck 的选项，例如 "force_all_fragments"。
    
       -f     强制检查即使文件系统看起来没有被挂载也要检查。
    
       -j external-journal
              使用指定的外部日志文件来恢复日志。
    
       -l     将系统的上次检查时间设置为当前时间，而不运行 e2fsck。
    
       -L bad_blocks_file
              使用指定的文件替代 /var/lib/badblocks 文件。
    
       -m bad_blocks_behavior
              将指定的坏块处理行为应用于坏块列表。"continue" 将跳过发现的坏块，"cancel" 将取消文件系统的检查。
    
       -n     显示要执行的操作，但不实际执行。
    
       -P progress_fd
              将 e2fsck 的进度信息写入指定的文件描述符。
    
       -r     从只读模式开始检查文件系统。
    
       -R region_size
              指定扫描的 region 大小。通常情况下，e2fsck 使用设备的区域大小。
    
       -S last_mounted_filesystem
              设置上次挂载的文件系统名。
    
       -T last_checked
              设置文件系统上次检查的时间。
    
       -t     在测试模式下运行 e2fsck（仅检查不执行任何修改）。
    
       -v     详细模式：显示详细信息。
    
       -V     显示 e2fsck 的版本信息并退出。
    
       -y     对所有问题都回答 "yes" 以自动修复它们。仅适用于非交互式模式。
    
       -z undo_file
              将任何所做的改变保存到指定的 undo 文件中。如果指定了 -Z 选项，则在修复完成后，所有的改变都将被撤销。
    
       -Z     撤销在执行此 e2fsck 过程期间所做的任何改变。
    
       device 要检查的设备文件或要检查的特定文件系统的设备文件。
    
       如果使用了 "-b 1024" 选项，则 e2fsck 会试图从偏移 1024 个字节的设备文件位置读取文件系统信息。如果使用了 "-b 8193" 选项，则 e2fsck 会试图从偏移 8193 个字节的设备文件位置读取文件系统信息。e2fsck 通常会从备份超级块位置开始，以防止主超级块已经损坏。
    
       e2fsck 将扫描硬盘设备上的一个文件系统，并且报告和修复与文件系统有关的错误。它尝试修复文件系统的错误，但是可以修复的错误取决于文件系统的状态、硬件和 e2fsck 的版本。

示例
       e2fsck /dev/sda1

e2undo - 用于撤销对 ext2/ext3/ext4 文件系统的更改。

概要：
    e2undo [选项] undo_file device

描述：
    e2undo 用于撤销对 ext2/ext3/ext4 文件系统的更改。它会根据提供的 undo_file 恢复文件系统到之前的状态。undo_file 是由 e2fsck -z 选项生成的。

选项：
    -n     不要执行任何操作，仅显示将要执行的操作。
    -r     恢复文件系统到之前的状态。
    -v     显示详细信息。

参数：
    undo_file   包含要撤销的更改的文件。
    device      要恢复的设备文件或特定文件系统的设备文件。

示例：
    e2undo -r undo_file /dev/sda1
